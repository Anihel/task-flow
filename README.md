# Pet project Task flow

## Назначение проекта
Менеджер задач, который помогает небольшой команде организовывать
и отслеживать выполнение задач.

## Основной сценарий
Зарегистрироваться -> аутентифицироваться -> создать проект -> создать задачу -> назначить исполнителя или исполнителей -> задать срок задачи -> изменить статус задачи.

## MVP
Регистрация пользователя, аутентификация пользователя, создание проекта, создание задачи, установка сроков, изменение статусов задачи, назначение людей на задачи, удаление 
проектов и задач.

## Правила предметной области
- Проект может быть создан без дополнительных участников, но создатель автоматически будет участником.
- Проект создаёт любой пользователь, но управлять его участниками может только его создатель.
- У задачи может не быть исполнителей или быть несколько. Исполнителем задачи может быть только участник проекта.
- У задачи есть статусы: `BACKLOG`, `IN_PROGRESS`, `TESTING`, `DONE`.
- У проекта обязательна дата начала и не обязательна дата окончания.
- Срок задачи может отсутствовать.
- Если проект удаляется, то удаляются все его задачи и связи с участниками.
- При удалении участника из проекта его связи с задачами удаляются, но сами задачи остаются.
- Удалять проект и задачи может только создатель проекта.

## Стек технологий
- Java 21, Spring Boot, Spring Data JPA, Spring Web, Hibernate, PostgreSQL, Flyway, Lombok.
